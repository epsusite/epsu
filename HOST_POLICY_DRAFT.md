# Epsu Host Policy Draft

This draft is for platform operations. It is not the same thing as the public Terms of Service, Privacy Policy, or Community Guidelines.

## Purpose

- A host is a temporary community operator for an Epsu
- A host does not own the Epsu
- Host access exists to help manage the community on behalf of Epsu

## Basic Rules

- A host must follow Epsu Terms of Service
- A host must follow Community Guidelines
- A host must use host powers in good faith
- A host must not abuse host powers to target rivals, friends, or critics unfairly
- A host must not treat the role as permanent ownership

## School Epsus

- A school host must be a current student there
- Epsu may ask for verification
- Verification should use school email first
- Student ID should only be used if needed

## Expected Conduct

- Stay active enough to manage the Epsu
- Review applications and moderation items in reasonable time
- Keep communication respectful
- Escalate serious issues to platform admin when needed
- Help with handoff when a new host takes over normally

## Misuse

A host may lose host access for reasons including:

- inactivity
- abuse of moderation powers
- repeated bad judgment
- harassment
- discrimination
- ignoring platform rules
- losing student eligibility in a school Epsu
- actions that put users or the platform at risk

## Platform Authority

- Epsu can remove host access at any time when needed for safety, compliance, or platform integrity
- Epsu may appoint an interim host
- Epsu may keep an Epsu under direct platform management when needed

## Future Commercial Terms

- If host terms later become paid, payment does not create ownership
- Any future host term should be revocable under clear rules
- Refund rules should be written separately in the paid host agreement
