# Epsu Business To-Do

This file tracks business and operations work separate from product code work.

## Immediate

- Soft launch to `3` schools and `1` regional Epsu
- Measure whether any Epsu gets real traction before building monetization around it
- Keep costs low and avoid rushing `OÜ` registration before there is a clear need

## Traction Checks

- Track active users per Epsu
- Track posts per active user
- Track replies per post
- Track reports per Epsu
- Track whether users come back after day `1` and day `7`
- Identify which school or region has the strongest organic activity

## Company Setup

- Register an Estonian `OÜ` when payments or formal contracts become necessary
- Open a separate company bank account once the `OÜ` exists
- Keep company money separate from personal money
- Make sure the company owns:
  - code
  - domain
  - brand
  - app store accounts
  - Supabase and other infrastructure accounts

## Data Room

- Create a simple company folder structure
- Keep these folders updated:
  - `company`
  - `legal`
  - `finance`
  - `product-metrics`
  - `contracts`
  - `infra-accounts`

## Policies And Compliance

- Keep Terms, Privacy Policy, and Community Guidelines updated as the product changes
- Keep delete/export/correction flows aligned with the written policies
- Add a real support or privacy contact method later
- Keep moderation and host action logs available for audit and review

## School Host Model

- Treat school control as a temporary `Host` term, not ownership
- Require hosts to be current students
- Verify by school email first
- Use student ID only if needed
- Define host term length clearly
- Define how host terms end early for inactivity, abuse, or policy breaches
- Define refund rules for early termination
- Define handoff rules from incumbent host to replacement host
- Write a Host Code and Host Performance Standard

## Regional Host Model

- Do not launch paid regional hosting too early
- Start with smaller towns or districts, not giant cities
- For large cities, consider district-level hosts instead of one host for the whole area
- Prefer activity-based eligibility before hard residency verification
- Add optional proof only when there is a dispute

## Monetization

- School host licensing is the first serious monetization path
- Regional ads are secondary and should stay direct-sale only at first
- Do not rely on third-party ad networks early
- Avoid letting hosts control final ad approval or money flow at first
- Be careful with paid unlocks for running many school Epsus

## Contracts

- If hosts stay normal users/customers, do not treat them as company staff
- If someone gets paid by the company or acts on its behalf, use a written agreement
- Keep all future monetization contracts revocable where necessary for safety and governance

## Funding

- Look for small local youth or project grants under `€500`
- Check municipality youth grants first
- Check student council, school, or university entrepreneurship support
- Keep larger startup grants for later if the product gets traction

## Exit Readiness

- Keep the cap table clean
- Do not promise equity casually
- Keep written records for any future ownership changes
- Keep product metrics snapshots over time
- Keep legal and financial records organized so the company can be reviewed later
