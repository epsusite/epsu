# Apple Review Notes Draft

Use this in App Store Connect review notes, adjusted to the actual reviewer account you provide.

## Core note

Epsu is an anonymous community app for local and school communities. Ordinary users do not see author identities, user profiles, direct messages, follows, or mentions. Users interact with anonymous posts inside moderated communities.

The app includes:
- in-app post reporting
- moderator and admin review tools
- temporary 24-hour mutes
- user-controlled blocking of anonymous authors from the user’s own feed
- in-app account deletion

## Login note

The app requires login because core functionality is account-based. Please use the reviewer credentials provided in App Review details to access the app.

## Posting model note

Posts are not released instantly. Epsu uses hourly post batches. Submitted posts are queued for the next UTC hourly release window and then deleted after their scheduled cycle expires.

## Permissions note

Notifications are optional and are used for moderation results and important community updates.

Photo library access is optional and is requested only if the user chooses a school logo while creating a school Epsu.
